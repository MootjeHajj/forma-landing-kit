# Brand contract

- `src/config/brand.ts`: product identity, headline, description, CTA, and example notice.
- `src/data/content.ts`: feature stories, use cases, and FAQ. Use verified product facts.
- `src/services/DemoBoardService.ts`: sample data repository, repository interface, and filtering service. Replace it with behavior relevant to the real product.
- `src/components/LandingPage.tsx`: composition and accessible interactive sections. Replace example pricing with the actual authorized offer.
- `src/app/globals.css`: original visual tokens, CSS illustrations, responsive styles, and reduced-motion handling.
- `src/app/icon.svg`: original example mark. Replace for the target brand.
- `src/app/layout.tsx`: metadata and language. The demonstration is `noindex`; choose indexing deliberately for a real site.

The kit includes original geometric illustrations and a fictional product interface. It contains no downloaded photos, fonts, video, portraits, brand badges, testimonials, or Supaste assets. System fonts require no bundled font files. Check the plugin's release license before redistribution; no license is inferred from public accessibility.
